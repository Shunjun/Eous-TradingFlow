## P4 — Workflow 引擎

| ID    | 功能点                  | 说明                                               | 验收标准                                                        |
| ----- | ----------------------- | -------------------------------------------------- | --------------------------------------------------------------- |
| P4-01 | 节点类型注册表          | NodeTypeRegistry，注册所有节点类型的元信息和执行器 | 可通过 type 字符串查找对应执行器                                |
| P4-02 | NodeExecutor 基类       | 定义 execute / validate / cleanup 生命周期         | 新增节点类型只需继承并实现 execute                              |
| P4-03 | Source 节点执行器       | 实时价格、历史K线、新闻源三个 Source 节点          | 节点执行后返回对应类型的数据                                    |
| P4-04 | Compute 节点执行器      | 技术指标（TA-Lib）、因子计算、Python 代码沙箱      | 输入 OHLCV + 参数，输出计算结果                                 |
| P4-05 | LLM 节点执行器          | LLM 信号分析、报告生成、自由对话，支持流式         | 输入 Prompt + 上游数据，输出结构化结果或 Markdown，支持流式推送 |
| P4-06 | Control 节点执行器      | 条件分支、并行分发、定时触发                       | 条件分支只执行匹配路径；并行分发下游同时执行                    |
| P4-07 | DAG 拓扑排序与调度      | 根据 nodes + edges 构建 DAG，分层并行执行          | 同层节点并行、层间串行，LLM 节点受并行限制                      |
| P4-08 | 变量插值引擎            | `{{nodeId.handleId.field}}` 语法解析与值替换       | 支持字段访问、数组切片、数组最后一项                            |
| P4-09 | 节点执行结果持久化      | 每次执行每个节点的 input/output/error 存入数据库   | 历史执行可查询，节点数据可回溯                                  |
| P4-10 | 执行状态 WebSocket 推送 | 节点开始/完成/失败/LLM流式内容实时推到前端         | 前端订阅执行 ID 后收到实时事件                                  |

| P5-07 | 工作流保存/加载     | 保存 nodes + edges 到后端，列表页可加载、删除、重命名           | CRUD 完整                                           |
| P5-08 | 工作流手动执行      | 点击运行按钮，画布节点实时高亮状态，LLM 节点流式显示            | 执行过程和结果在画布上可见                          |
| P5-09 | 从节点重跑下游      | 右键节点"从此重跑"，保留上游缓存                                | 上游不重跑，下游重新执行                            |
| P5-10 | 节点输出查看        | 点击已完成节点可查看其输入/输出数据                             | 数据以格式化 JSON 或表格展示                        |
